Connect Roblox

Link your Roblox account so Limited coinflips can load your public inventory and settle item trades after a win. This uses a one-time trade session from your logged-in browser — same idea as connecting a bot middleman.

How to get your trade session
  1. Open roblox.com in Chrome/Edge while logged in.
  2. Press F12 → Application (Chrome) or Storage (Firefox).
  3. Left sidebar → Cookies → https://www.roblox.com.
  4. Select the long session row (name starts with a dot), copy its Value only.
  5. Paste it in the Trade session field above.
  6. Roblox → Settings → Privacy → set Inventory to Public / Everyone.

Browsers block automatic session reads across sites, so a one-time paste is required. The token is stored only on your BloxBet server for trade settlement.
